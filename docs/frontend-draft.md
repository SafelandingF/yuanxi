# 缘析页面与交互

当前前端已经接入真实豆包 Seed 2.0 Pro，不再使用计时器模拟 AI。后端接口与启动方式见根目录 README.md。

## 视觉

暖白背景、陶土橙强调色、浅苔色侧栏。左下角可以切换橄榄绿、雾海蓝。标题使用本机衬线字体，正文与表单使用无衬线字体；人物与装饰均为本地抽象插画。已移除顶部英文标语和 DEMO 标签；人物的虚构属性仍在候选卡片和页脚说明。

## 页面

- **了解自己**：填写昵称、年龄、城市、关系目标、兴趣、生活节奏、陪伴频率及补充文本。提供一键示例、基础校验和本机草稿保存。
- **发现匹配**：显示结构化关系画像、三位候选的共同点和潜在差异，以及全部 120 位候选的 ECharts 分布图。模型观察以 Markdown 实时展开。
- **安排约会**：选择当前推荐候选，输入餐饮偏好、忌口、人均预算和开始时间，展示约会时间线、费用及反馈调整。修改条件后旧计划失效，需要重新生成。

## 状态

执行阶段来自真实后端事件，可展开工作记录。结构化结果完整校验后显示；文字片段边生成边渲染。停止或切换流程中止当前请求，保留已有内容；旧请求不能覆盖新结果。失败不冒充完成，显示原因和重新生成入口。用户上滚阅读时暂停跟随，提供回到最新内容按钮。

## 组件

shadcn-vue 基础控件、AI Elements Vue MessageResponse、vue-stream-markdown、按需引入的 ECharts。Markdown 与图表延迟加载。Markdown 依赖的部分可选富文本资源较大，因此生产构建有大分块提示；构建成功，首屏不直接加载结果组件。

## 验证边界

已进行类型检查、生产构建与本地 HTTP 检查。遵循用户的 workspace 约定，没有自动操作浏览器做视觉验收；可在本地预览检查实际观感。
